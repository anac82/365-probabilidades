# 365 Probabilidades
## Decidindo com dados, um dia de cada vez.

Projeto pessoal de 365 dias criando modelos estatísticos de situações universais da vida humana.



**Plataformas:** GitHub · Substack · Instagram  
**Hashtag:** #365Probabilidades

---

## Estrutura de pastas

```
365Probabilidades/
├── modelos/          → modelos por mês (espelhado no GitHub)
├── rascunhos/        → buffer de conteúdo (NÃO vai para o GitHub)
├── publicados/       → arquivo dos já publicados
├── assets/           → logos, paleta, templates visuais
├── guinness/         → evidências e documentação do recorde

└── _templates/       → templates de modelo para copiar
```
